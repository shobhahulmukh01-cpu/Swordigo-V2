# Alpha.4 plan — extend the supplied adventure

Base: published alpha.3 (`e5687c9`). Canonical runtime remains `index.html` → existing Canvas scripts. No engine/character/world replacement and no official Swordigo affiliation. The parallel `src/` prototype remains archived.

## Council decisions
Four independent councils reviewed gameplay, visual direction, player journey and reliability, then cross-reviewed each other's source-backed proposals. The important correction: per-realm journal routes already exist, and three optional rooms are available before the original ending; only Archive requires completion. Do not duplicate those features or hide existing early exploration.

| Work | Player value | Boundary |
|---|---|---|
| Pure next-action guidance and session-only delivery following | Understand rune release versus collection, local room work, recipients and legal next doors | No forced tutorials, hidden quest flags, free facts or room teleportation |
| Descriptive map paths and campaign/optional journal separation | Resume an interrupted journey without a global spoiler checklist | Existing travel predicates remain authoritative |
| Explicit completed-save continuation and outcome-aware return letter | A coherent rebuilding continuation while retaining both original endings | No new ending or compulsory delivery sweep |
| Actual current→next shrine stats | Make existing build choices informed before spending | Economy, damage, caps, refill and combat timing unchanged |
| Post-Engine Dawnstep return lamp | Earned ability becomes a useful traversal payoff | No first-approach bypass, healing, currency, new anchor or persisted flag |
| Original optional-room paintings and restrained actor staging | Distinct places, clearer combat state and visible committed repairs | Retain three original campaign paintings, hitboxes, warning lanes and reduced-motion cues |
| Progressive fixture diagnostics and bounded four-cell causal screen | Preserve first-divergence evidence when setup or rollback stalls | No retry-to-green, timeout widening, reseeding or production-certification claim |

## Preservation and failure gates
Keep all original IDs, V3 and V4 journeys, actors, three worlds, six runes, guardians, both endings, Echo Gauntlet, four optional rooms and explicit continuation authority. Followed tasks are not serialized. UI helpers are read-only. Recorded purchases/deliveries still depend on real simulation and successful storage. Import/replacement remains fail-closed.

Premortem: guidance spoils exploration → discovered/local-first, optional tracking; preview lies → compare real effective formulas and purchases at caps/ranks; shortcut bypasses victory → requirements/combat/destination and earned-input proof; art suggests false platforms → background-only composition and individual live-camera review; motion hides danger → static readable state and warning clearance; diagnostics erase failure → progressive bounded records, unchanged predicates; new source invalidates evidence → one final integration freeze and source-bound rerun.

## Tooling and qualification
Reviewed supplied `repos.md`; retain existing Node/Playwright/GitHub workflow. Existing REA report is static analysis of the supplied source, not certification of this new milestone. Lore prebuilt CLI cannot run on this host; do not replace system libraries or migrate VCS to claim usage. No commercial game binaries, assets or code are extracted. Public Swordigo descriptions inform broad exploration/progression/touch principles only.

Parent owns SRI/build, serial heavy suites, visual capture coordination, Git/PR/deployment and final byte verification. Council/implementation agents own nonoverlapping files. Required evidence separates ordinary-input earned completion, native UI interaction, synthetic render fixtures and human/device qualification. Original rollback timeout, incomplete prior 12-trial experiment and initial alpha.3 CI failure remain preserved. Four new screening cells, even if all pass, cannot establish historical cause or production repeatability. Human discovery/pacing, real hardware/controller/browser matrix, accessibility and owner asset/trademark/license decisions remain open until actually reviewed.
