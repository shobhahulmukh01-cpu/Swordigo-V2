# Council synthesis and validation loops

## Execution disclosure
Parallel subagent startup repeatedly failed in the previous session. One agent performed the research, creative, systems, architecture and QA roles sequentially. These are role-based review rounds, not invented conversations with independent agents. Epic Lore installation was canceled and remains uninstalled.

## Round 1 — competing directions
A. Extend Canvas baseline: safest compatibility, limited visual leap.
B. Rebuild as full 3D exploration: excessive scope and camera/control risk.
C. Side-on 2.5D original campaign: preserves the core feel while modernizing presentation. **Selected C**, retaining A as legacy fallback.

## Round 2 — challenge
Creative wanted 26+ rooms, 14 enemy species and extended quests. Engineering challenged scope/validation. Resolution: 22 rooms, shared enemy archetype behaviors with biome variants, six guardians and a final multi-phase duel. Original meshes are game content, not borrowed Swordigo art. No fabricated performance, duration or trademark guarantees.

## Round 3 — release contract
1. Write plan before implementation.
2. Modular deterministic simulation.
3. Input-only campaign completion proof.
4. Strict save tests and shrine/death recovery.
5. Browser tests including project prefix, touch, controller fixture, pause and reload.
6. Review screenshots, fix defects, repeat.
7. Keep baseline checks intact on the legacy entry.
8. Security scan and dependency audit.
9. GitHub PR/CI before merge.
10. Publish measured scope and remaining gates, rather than claiming commercial certification.

## Change-control rule
Implementation deviations are documented in `docs/QA.md`. Do not quietly turn planned mechanics into delivery claims. Initial target is a playable release candidate; commercial-production readiness requires device/human validation beyond this sandbox.
