Camera state is render-only and world-bounded. Letter entitlement uses only the active story journey. Diagnostic artifacts cannot include raw logs, screenshots, profiles, journeys, credentials or arbitrary report strings.

Final acceptance must distinguish earned, native, synthetic-pad, positioned and imported fixtures; retain failures; replay campaign/routes/rush/endings; validate save authority and exact build/offline bytes; and inspect viewport/motion/fallback captures.
